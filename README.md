# Учёт личных финансов

Консольное приложение на Python для учёта доходов и расходов. Данные хранятся в базе данных SQLite.

## Описание

Программа помогает вести личный бюджет: записывать доходы и расходы, разбивать их по категориям, смотреть баланс и анализировать, на что уходит больше всего денег.

## Возможности

- Добавление доходов и расходов с датой, категорией и комментарием
- Просмотр всех операций в виде таблицы
- Статистика: общий доход, расход, баланс и доля расходов по категориям с текстовой диаграммой
- Удаление операций по ID
- Экспорт данных в CSV-файл (открывается в Excel)
- Проверка вводимых данных (сумма, дата, категория)

## Технологии

- Python 3.8+
- `sqlite3` — база данных
- `csv` — экспорт данных
- `datetime` — работа с датами

Внешние библиотеки не нужны.

## Запуск

```bash
python finance_tracker.py
```

При первом запуске автоматически создаётся файл базы данных `finance.db`.

## Пример работы

```
===== УЧЁТ ФИНАНСОВ =====
1. Добавить операцию
```

## Структура базы данных

Таблица `records`:

| Поле     | Тип     | Описание                       |
|----------|---------|--------------------------------|
| id       | INTEGER | Уникальный номер записи        |
| date     | TEXT    | Дата операции (ГГГГ-ММ-ДД)     |
| kind     | TEXT    | Тип: «доход» или «расход»      |
| category | TEXT    | Категория операции             |
| amount   | REAL    | Сумма (больше нуля)            |
| note     | TEXT    | Комментарий                    |

## Основные функции

| Функция          | Назначение                                  |
|------------------|---------------------------------------------|
| `init_db()`      | Создаёт таблицу в базе данных               |
| `add_record()`   | Добавляет операцию                          |
| `get_records()`  | Возвращает все операции                     |
| `delete_record()`| Удаляет операцию по ID                      |
| `menu_stats()`   | Считает и выводит статистику                |
| `menu_export()`  | Выгружает данные в CSV                      |
